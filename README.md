# Daily Wellness Tracker

A simple, mobile-friendly web app for tracking daily wellness habits. It is built with plain HTML, CSS and JavaScript, with no frameworks, no libraries and no build step. Your records are saved in your browser, so nothing is sent to a server.
## Features
Six Habits to Tracked Each day 
Water (glasses)
Walking (steps count)
Exercise (minutes)
Sleep (hours)
Meditation (minutes)
